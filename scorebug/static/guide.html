VolleyScore Guide

Quick manual for scoring, overlays and OBS

Quick Start

Run the exe, allow firewall, open Control Panel and add browser sources in OBS.

  • http://localhost:8000/control_panel — control from host or phone on same LAN (http://<IP>:8000/control_panel)
  • Allow Windows Firewall when prompted.
Scoring & Sets

Points auto-complete sets at 25 (15 in 5th) with 2-point lead. Use +/- or keys 1-4. Sets auto-increment and reset points.

  • Keys: 1/2 +1 point, Shift+1/2 -1, 3/4 +1 set
  • currentSet advances automatically, timeouts reset to 2.
Timer & Timeouts

Timer auto-starts on first point. Start/Pause/Resume/Reset. Timeouts: 2 per team per set, reset on new set.

  • Keys: T start/pause/resume, Shift+T reset, U/I timeout +/-
  • All events are appended to logs/match_report_YYYY-MM-DD.csv in order (daily, survives reboot).
Overlays & Visibility

Standard scorebug always visible. Toggle Sets/Timer/Timeouts/History via Overlay Display — they fade in/out. Stack all browser sources in one OBS scene.

Formations & Teams

Set 6 starters per team in Teams tab. Home/Away/Dual formation overlays show them.

  • Teams tab → names, colors, logos, 6 players → Save Team Settings.
  • Settings → Overlay Theme (5 shared colors, formations keep team colors).
Keyboard Shortcuts

All match controls have remappable shortcuts (Settings → Keyboard Shortcuts). While typing, shortcuts are ignored.

  • Settings → click a key → press new combo → Apply.
  • Duplicate combos rejected; × unbinds.
Daily Log

All points, timeouts and timer events are appended in order to logs/match_report_YYYY-MM-DD.csv per day. Old files kept.

One match per day: same file appended even after PC shutoff (header once). Columns include homeTimeouts, timerElapsed, currentSet (all but theme).
